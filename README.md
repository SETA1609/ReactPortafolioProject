# ReactPortafolioProject

Personal portfolio built with React and Vite showcasing selected GitHub projects and a contact form. Content is localized in English, Spanish and German.

## Development

- `npm run dev` – start local development server
- `npm run build` – create production build

## Testing

Jest and React Testing Library verify UI behaviour.

- `npm test` – run the test suite

## Linting

ESLint checks the codebase using a conventional React/TypeScript configuration.

- `npm run lint` – run ESLint over the `src` directory

## Continuous Integration

GitHub Actions executes linting and tests on every pull request to ensure code quality before merging.
